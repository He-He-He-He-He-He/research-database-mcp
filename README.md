# 研究数据库 MCP

为支持本机 MCP 的 AI 提供公开统计、学术题录和其他研究数据库的发现与查询能力。

**[下载干净发行包](https://github.com/He-He-He-He-He-He/research-database-mcp/releases/latest/download/research-database-mcp-v1.1.0.zip)** · [安装指南](AI安装指南.md) · [功能边界与隐私](功能边界与隐私.md)

## 交给自己的 AI 安装

下载 Release ZIP，解压后把整个文件夹交给自己的 AI，并说：

> 请阅读《AI安装指南.md》，帮我安装并连接这个 MCP。先问我使用“部分功能”还是“全部可选功能”。安装到独立用户目录，不要修改发行文件夹、覆盖其他连接器配置或打印密钥。配置可以随时暂停，下次继续。

也可以在解压后的文件夹中运行：

```sh
python3 -B install.py --mode partial
```

需要 Python 3.10+、curl、网络和可运行 stdio MCP 的客户端。安装器在包外创建独立运行环境、生成接收者自己的连接配置，并输出待接入客户端的服务字段；不会自行覆盖现有客户端配置。Windows 可使用自己的 `python` 或 `py` 命令。直接克隆仓库安装时，安装器也只复制发行清单文件，不复制 Git 元数据。

## 两种模式

| 模式 | 行为 |
|---|---|
| `partial` 部分功能 | 开放 37 个免登录起步命令，不需要数据库账号或 API 密钥 |
| `full` 全部可选功能 | 保留上述能力，逐项引导注册/申请 API、配置自己的机构访问与其他扩展能力 |

选择 full 不要求一次完成。可以跳过等待审批的来源、暂停保存进度，并在下次接续。已有账号无需重复注册；密码与密钥不通过聊天或查询参数传递。

免登录起步来源包括世界银行、国家统计局公开栏目、国家法律法规数据库、最高检公开资料、Crossref、arXiv、PubMed/NCBI、USGS、NASA POWER、荷兰 CBS、英国 ONS、FAOSTAT 和 BIS。

扩展代码索引包含 3,753 个命令入口；**这是代码入口数量，不是可用数据库数量，也不代表全部来源已获授权。** 部分扩展需要自己的 API 凭据、机构订阅、浏览器执行能力、公开文件、额外依赖或源站适配。部分机构辅助代码带有特定学校的公开入口和页面判断，换学校需实际核验或适配。

## 提供的 MCP 工具

| 工具 | 用途 |
|---|---|
| `research_setup` | 选择模式、逐步配置、保存进度、跳过、暂停与恢复 |
| `research_discover` | 按关键词发现查询命令及需求 |
| `research_help` | 查看命令参数 |
| `research_query` | 执行实际查询 |
| `research_verify` | 执行某个可选来源的测试查询并记录状态 |

连接后先调用 `research_setup`。查询时先发现来源，再查看参数；结果应保留原值、时间、单位、出处、分页和限制。

## 网络与机构认证

IP 认证取决于 **MCP 实际运行的机器**。该机器处在学校认可的网络，学校订购了资源且对应适配器正常时，无个人登录要求的资源可以用机构 IP 访问。云端 AI 不会自动继承用户电脑的校园网络、浏览器会话或钥匙串。

## 隐私与再次分发

发行包不带发送者的个人资料、邮箱、手机号、账户、密钥、浏览器会话、研究结果或本机生成配置。运行环境和进度在接收者的包外目录中保存；本服务不向发送者回传查询或账号数据。

再次分享建议运行：

```sh
python3 -B pack_release.py
```

专用脚本只导出原始许可清单内文件，排除新增的虚拟环境、配置、进度、缓存及 macOS 附加元数据；原始代码被修改时会拒绝打包。不要直接压缩用户自己的安装目录。

数据库及数据内容的许可仍由提供方规定；本仓库不分发订阅内容或授权凭据，也不授予任何数据库额外使用权。

## 验证

对解压后的 Release 发行包：

```sh
python3 -B verify_manifest.py
python3 -B self_check.py
python3 -B test_distribution.py
```

本版本通过 18 项离线自检、8 项分发回归测试，以及独立目录的全新安装、一次免登录真实查询和跨进程暂停恢复检查。严格发行包检查会拒绝额外文件，因此在含 `.git` 的仓库工作目录中宜使用 `pack_release.py` 导出干净 ZIP 后再做严格检查。

macOS 是主要验证平台；Windows/Linux 尚未逐项完成全部扩展功能验收。源站的改版、限流、网络与授权状态可能影响实时可用性。详见 [验收说明](验收说明.md)。
