# 研究数据库 MCP

**让 AI 按你的问题，去查公开统计、学术文献题录和其他研究数据库。**

你提出研究问题，AI 通过这个 MCP 发现数据源、确认查询参数、发起实际请求，再把返回结果整理成带出处的回答。它提供可重复使用的查询能力；需要什么，再查什么。

### v1.3.0 的重点

- 改为**一般、浙大内网、登录**三种模式；公开功能不再受 42 条起步样例限制。
- 校正按整个依赖模块扫描导致的权限误标；现在追踪每条命令可达的函数，区分公共查询、机构身份及个人凭据。
- 根据查询的实际连接失败自动跳过不可达命令，继续其他来源；不会因为是国外网站或没有代理就一概跳过。
- 保留原有配置、暂停位置和凭据。旧 `partial` 自动对应 `general`，旧 `full` 对应 `login`。
- 42 条 `starter` 仅表示起步回归样例，**不是一般模式的功能总数，也不是 42 个数据库**。[查看验证范围](docs/VALIDATION.md)。

| “我有自己的数据库账号，帮我逐步接入。” | 13 个可选 API 的引导、独立凭据存储、测试记录 | 注册、审批、额度及数据权限以对应来源为准 |

## 它怎样工作？

```mermaid
flowchart LR
    A[你提出问题] --> B[AI 选择数据源]
    B --> C[MCP 查看参数并执行查询]
    C --> D[公开接口或已配置的数据源]
    D --> E[返回结果和限制信息]
    E --> F[AI 核对口径并给出出处]
```

通常先调用 `research_discover`，再 `research_help`，最后 `research_query`。不同来源的数据结构可能不同；AI 仍需核对单位、年份、地理范围、分页和缺失值。

本服务会按请求查询上游；它不自动连续抓取所有数据库，不统一保存你的全部查询历史。部分扩展会下载或缓存所需的公开文件，存放位置与发行文件夹隔离。

## 交给自己的 AI 安装

1. [下载 Release ZIP](https://github.com/He-He-He-He-He-He/research-database-mcp/releases/latest)，解压。
2. 把**整个解压文件夹**交给能运行本机 MCP 的 AI/代理环境。
3. 把下面这段话一起发给它：

> 请阅读《AI安装指南.md》，帮我安装并连接这个研究数据库 MCP。先使用一般模式，开放全部无需个人凭据和机构网络的命令；需要时再选浙大内网或登录模式。请安装到包外的独立用户目录，只追加本服务，不覆盖其他 MCP 配置，不打印密钥。连接后先查状态，再用一个免登录来源实际查询，确认能用。

如果自行安装，在解压文件夹内运行：

```sh
python3 -B install.py --mode general
```

需要 **Python 3.10+、curl、网络和能启动 stdio MCP 子进程的客户端**。Windows 可使用自己的 `python` 或 `py` 命令。安装器会输出本机连接字段；AI 需要按当前客户端支持的方式接入，看到五个工具并完成调用才算连接成功。

安装环境、连接配置和进度保存在包外。发行文件夹安装前后保持不变。详细步骤、目录说明和连接验收见 [快速开始](docs/QUICKSTART.md)。

## 三种模式怎样选？

| 模式 | 开放范围 | 仍须满足的条件 |
|---|---|---|
| `general` 一般模式（默认） | 全部无需个人登录/密钥、无需机构网络的查询与文件解析命令 | 网络、依赖、参数及实际公开文件；不需为公开功能注册 |
| `zju` 浙大内网模式 | 一般模式 + 依赖机构 IP/内网的命令 | **运行 MCP 的机器**具备源站认可的校园网络身份、学校订购及正常适配器 |
| `login` 登录模式 | 前两类 + 需要个人账号、API 密钥等凭据的命令 | 仅为需要的来源配置自己的凭据；若来源还需机构网络，仍须另行满足 |

三种模式是访问条件分类，不是收费等级。切换不会替你登录、购买订阅、继承发送者身份，也不要求逐个注册所有来源。登录模式可随时暂停并保存步骤；切换模式也不删除配置。

例如，对 AI 说“先用一般模式”“我在浙大网络上，切到浙大内网模式”或“我需要 EIA，按步骤接入这个来源”。也可调用 `research_setup(action="select", mode="general")`（或 `zju` / `login`）。

旧配置兼容：`partial` → `general`，`full` → `login`；进度、暂停标记及正在处理的来源保留。

### 网络不通怎么办？

按需查询，不在启动时探测全部网站。遇到明确 DNS、连接、代理、证书或超时失败，返回 `skipped: true` 及原因，默认 60 秒内跳过同一命令，AI 应继续发现并查询其他来源。超时也可能是源站响应慢，记录不会断言是地区封锁。HTTP 401/403/429、缺文件和缺依赖**不冒充断网**。

60 秒后自动允许重试；网络切换后可 `research_setup(action="network_reset")` 立即清除等待。不会自动切换你的代理、关闭证书校验或永久禁用外国来源。静态代码无法可靠判断用户“有没有梯子”，以实际请求为准。

完整步骤、来源标识和凭据设置见 [配置与暂停恢复](docs/CONFIGURATION.md)。

## 数据源覆盖到什么程度？

能力分为三层：

1. **公开功能与起步样例**：一般模式开放所有无需个人凭据/机构网络的命令；其中 42 条作为起步样例，涵盖公开统计、学术题录、法律检索、气候与地震数据等；提供命令清单与使用示例。
2. **可选 API 配置层**：为 EIA、CiNii、ASEANstats、UNDP、Elsevier、WTO、Springer、Web of Science Starter、IOM 两类产品、IATI、联合国人口、CAS Common Chemistry 提供逐步引导和测试入口。
3. **扩展代码层**：其他公开/机构来源、浏览器响应辅助模块与文件解析器。部分需要自己的机构访问、公开文件、额外依赖或源站适配；保留代码不等于验收完成。

完整的免登录命令、各来源适用问题、可选项和已知限制，见 [数据源与能力清单](docs/DATA_SOURCES.md)。机器可读索引见 [command_catalog.json](command_catalog.json)。

## 校内网络、登录和云端运行

IP 认证取决于 **MCP 实际运行的机器**。该机器处在学校认可的网络、学校订购了资源且相应适配器正常时，无个人登录要求的库可以通过机构 IP 访问。

如果 AI 在云端容器运行，用户电脑连着校园网也不会自动让容器拥有校园 IP。账号、学校订阅、浏览器会话、钥匙串和密码均不随此包分发。

部分浏览器辅助代码保留特定学校的公开入口或页面判断，换机构需要核验或适配；这些 `.mjs` 文件需要 AI 的浏览器执行环境，五个 MCP 工具本身不会自动控制任意浏览器。

## MCP 工具一览

| 工具 | 用途 | 最小调用参数示例 |
|---|---|---|
| `research_setup` | 模式、状态、配置步骤、暂停恢复 | `{"action":"status"}` |

| `research_help` | 查看某个命令的参数 | `{"command":"crossref"}` |

## 隐私、验证和再次分享

- 发行包不包含发送者的个人资料、联系方式、账号、密钥、浏览器会话、研究结果或生成的本机连接配置。
- 本服务不向发送者回传查询或账号数据。实际查询会发送给对应数据源，并使用接收者自己的运行环境和网络。
- 凭据使用独立系统安全存储或由接收者显式配置；进度在包外保存。
- 再次分享请使用 `python3 -B pack_release.py`。它只导出发行清单文件，排除新增的虚拟环境、配置、缓存及 macOS 附加元数据。不要直接压缩自己的运行目录。
- 数据库、接口和内容的使用条件仍由对应提供方规定；此包不附送机构订阅或第三方数据使用授权。

发行版具备 18 项基础离线自检、8 项分发回归、21 项诊断/发现检查及 21 项访问模式/网络跳过检查。此前已完成公开来源的抽样实测，以及独立目录全新安装、免登录查询和跨进程暂停恢复验证；它们不能证明每个扩展命令或源站始终可用。详见 [验收说明](验收说明.md) 与 [功能边界与隐私](功能边界与隐私.md)。

68 项离线检查与公开查询样例分开统计，具体系统和来源结果见 [验证记录](docs/VALIDATION.md)。
