# 研究数据库 MCP

**让 AI 按你的问题，去查公开统计、学术文献题录和其他研究数据库。**

你提出研究问题，AI 通过这个 MCP 发现数据源、确认查询参数、发起实际请求，再把返回结果整理成带出处的回答。它提供可重复使用的查询能力；需要什么，再查什么。

## 可以帮你做什么？

| 你可以这样问 AI | 可用的起步能力 | 需要注意 |
|---|---|---|
| “比较几个国家近十年的人口变化，给出原始值和出处。” | 世界银行国家、指标元数据、年度序列 | 先确定指标口径，区分缺失值与零 |
| “查可再生能源的研究文献，列出标题、年份、DOI 和链接。” | Crossref、arXiv、PubMed/NCBI | 题录可检索不代表论文全文可下载 |
| “查与消费者权益有关的法律，并核对效力状态。” | 国家法律法规数据库关键词检索 | 逐项核对正文与效力；相关性结果不代表严格逐字命中 |
| “查国家统计局最新公开的经济运行报告入口。” | 国家统计局相关公开栏目目录 | 这是特定栏目入口，不是国家统计局全部数据接口 |
| “查某地点指定日期的气温或降水。” | NASA POWER 日数据及参数信息 | 查明坐标、单位、时间标准和数据来源 |
| “查英国/荷兰公开统计，或农业、金融数据。” | ONS、CBS、FAOSTAT、BIS 的发现、结构及查询入口 | 先获取数据集和维度代码，再提取观测值 |
| “我有自己的数据库账号，帮我逐步接入。” | 13 个可选 API 的引导、独立凭据存储、测试记录 | 注册、审批、额度及数据权限以对应来源为准 |

更多可直接交给 AI 的提问和实际工具参数，见 [使用示例](docs/EXAMPLES.md)。

## 它怎样工作？

```mermaid
flowchart LR
    A[你提出问题] --> B[AI 选择数据源]
    B --> C[MCP 查看参数并执行查询]
    C --> D[公开接口或已配置的数据源]
    D --> E[返回结果和限制信息]
    E --> F[AI 核对口径并给出出处]
```

通常先调用 `research_discover`，再 `research_help`，最后 `research_query`。不同来源的数据结构可能不同；AI 仍需核对单位、年份、地理范围、分页和缺失值。

本服务会按请求查询上游；它不自动连续抓取所有数据库，不统一保存你的全部查询历史。部分扩展会下载或缓存所需的公开文件，存放位置与发行文件夹隔离。

## 交给自己的 AI 安装

1. [下载 Release ZIP](https://github.com/He-He-He-He-He-He/research-database-mcp/releases/latest)，解压。
2. 把**整个解压文件夹**交给能运行本机 MCP 的 AI/代理环境。
3. 把下面这段话一起发给它：

> 请阅读《AI安装指南.md》，帮我安装并连接这个研究数据库 MCP。先问我选择“部分功能（免登录）”还是“全部可选功能（逐步配置、可暂停）”。请安装到包外的独立用户目录，只追加本服务，不覆盖其他 MCP 配置，不打印密钥。连接后先查状态，再用一个免登录来源实际查询，确认能用。

如果自行安装，在解压文件夹内运行：

```sh
python3 -B install.py --mode partial
```

需要 **Python 3.10+、curl、网络和能启动 stdio MCP 子进程的客户端**。Windows 可使用自己的 `python` 或 `py` 命令。安装器会输出本机连接字段；AI 需要按当前客户端支持的方式接入，看到五个工具并完成调用才算连接成功。

安装环境、连接配置和进度保存在包外。发行文件夹安装前后保持不变。详细步骤、目录说明和连接验收见 [快速开始](docs/QUICKSTART.md)。

## 两种模式怎样选？

| | `partial` 部分功能 | `full` 全部可选功能 |
|---|---|---|
| 适合谁 | 希望先使用无需账号的公开查询 | 希望逐步配置更多来源 |
| 起步接口 | 42 个免登录命令 | 同样可用 |
| 扩展命令 | 未开放；调用时提示切换模式 | 允许尝试，但仍须满足相应要求 |
| 注册/密钥 | 无需数据库账号或 API 密钥 | 仅为你需要的来源配置自己的账号/凭据 |
| 中途暂停 | 可以直接使用现有能力 | 可以暂停、跳过等待项、以后继续 |
| 切换模式 | 不清空以前的配置进度 | 不要求一次配置完所有来源 |

`full` 是工具的配置范围，**不代表已经获得全部数据库授权，也不是网站登录或订阅的替代品**。有些扩展本身就是公开来源，切换后不需要注册；有些需要 API 审批、学校订阅、公开文件或额外适配。

例如，你可以对 AI 说：

> 我先只用公开查询。以后需要时，再配置某几个 API。
>
> 今天配置到这里，保存进度。下次从未完成的步骤继续。

完整步骤、来源标识和凭据设置见 [配置与暂停恢复](docs/CONFIGURATION.md)。

## 数据源覆盖到什么程度？

能力分为三层：

1. **免登录起步层**：42 个命令，涵盖公开统计、学术题录、法律检索、气候与地震数据等；提供命令清单与使用示例。
2. **可选 API 配置层**：为 EIA、CiNii、ASEANstats、UNDP、Elsevier、WTO、Springer、Web of Science Starter、IOM 两类产品、IATI、联合国人口、CAS Common Chemistry 提供逐步引导和测试入口。
3. **扩展代码层**：其他公开/机构来源、浏览器响应辅助模块与文件解析器。部分需要自己的机构访问、公开文件、额外依赖或源站适配；保留代码不等于验收完成。

完整的免登录命令、各来源适用问题、可选项和已知限制，见 [数据源与能力清单](docs/DATA_SOURCES.md)。机器可读索引见 [command_catalog.json](command_catalog.json)。

## 校内网络、登录和云端运行

IP 认证取决于 **MCP 实际运行的机器**。该机器处在学校认可的网络、学校订购了资源且相应适配器正常时，无个人登录要求的库可以通过机构 IP 访问。

如果 AI 在云端容器运行，用户电脑连着校园网也不会自动让容器拥有校园 IP。账号、学校订阅、浏览器会话、钥匙串和密码均不随此包分发。

部分浏览器辅助代码保留特定学校的公开入口或页面判断，换机构需要核验或适配；这些 `.mjs` 文件需要 AI 的浏览器执行环境，五个 MCP 工具本身不会自动控制任意浏览器。

## MCP 工具一览

| 工具 | 用途 | 最小调用参数示例 |
|---|---|---|
| `research_setup` | 模式、状态、配置步骤、暂停恢复 | `{"action":"status"}` |
| `research_discover` | 按关键词寻找命令与需求 | `{"keyword":"学术","starter_only":true,"limit":5}` |
| `research_help` | 查看某个命令的参数 | `{"command":"crossref"}` |
| `research_query` | 用字符串参数数组执行查询 | `{"command":"crossref","args":["renewable energy","--rows","3"]}` |
| `research_verify` | 测试一个可选来源并记录结果 | `{"source":"eia"}`，需先完成相关配置 |

调用和返回结构、CLI 用法见 [架构与开发说明](docs/ARCHITECTURE.md)。

## 隐私、验证和再次分享

- 发行包不包含发送者的个人资料、联系方式、账号、密钥、浏览器会话、研究结果或生成的本机连接配置。
- 本服务不向发送者回传查询或账号数据。实际查询会发送给对应数据源，并使用接收者自己的运行环境和网络。
- 凭据使用独立系统安全存储或由接收者显式配置；进度在包外保存。
- 再次分享请使用 `python3 -B pack_release.py`。它只导出发行清单文件，排除新增的虚拟环境、配置、缓存及 macOS 附加元数据。不要直接压缩自己的运行目录。
- 数据库、接口和内容的使用条件仍由对应提供方规定；此包不附送机构订阅或第三方数据使用授权。

发行版具备 18 项离线自检和 8 项分发回归检查。此前已完成公开来源的抽样实测，以及独立目录全新安装、免登录查询和跨进程暂停恢复验证；它们不能证明每个扩展命令或源站始终可用。详见 [验收说明](验收说明.md) 与 [功能边界与隐私](功能边界与隐私.md)。

46 项离线检查与公开查询样例分开统计，具体系统和来源结果见 [验证记录](docs/VALIDATION.md)。
