## v1.1.1 · 2026-11-03

本次重点是让接收者读懂项目、知道从哪里开始，并能区分“立即可用的起步命令”和“需要自己的配置/适配的扩展”。

- 重写首页：补充用途、研究场景、调用流程、两种模式、覆盖分层、网络与机构认证、隐私和文档导航。

- 新增使用示例：统计、文献、法律、公开报告、气候/地震、数据集发现，以及配置暂停恢复。
- 新增配置指南、常见问题和架构说明，明确凭据保存、进度、云端/校园网差异及错误分类。
- 修正公开 `law-search` 命令被模块依赖扫描误标为需凭据/机构的元数据；不改变检索逻辑。
- 将新增文档逐一加入发行白名单，继续排除运行配置、虚拟环境、缓存、凭据和个人资料。
