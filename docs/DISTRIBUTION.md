# 1.6.0 分发与接收说明

[返回首页](../README.md) · [给AI的安装指南](INSTALL.md) · [已验证范围](CAPABILITIES.md)

## 发什么

从[正式发布页](https://github.com/He-He-He-He-He-He/research-database-mcp/releases/tag/v1.6.0)下载 `research-database-mcp-v1.6.0.zip`。可以直接转发这个ZIP；需要文件夹时解压后转发完整文件夹，保留目录结构。

Release同时提供SHA256SUMS.txt，可核对ZIP摘要；解压后运行 `python3 -B tools/verify_manifest.py` 检查文件清单。它验证文件一致性及额外文件，不代替对接收渠道的信任判断。

不要转发已经安装后的运行目录、连接配置、进度、结果导出、浏览器会话或钥匙串。安装后的文件都在接收者自己的包外目录。若误把运行数据放入发行文件夹，严格校验会提示；使用 `python3 -B tools/pack_release.py` 重新导出白名单ZIP，不要直接全选压缩。

## 接收者发给自己的AI

> 请阅读这个文件夹的 docs/INSTALL.md，帮我安装并连接研究数据库MCP 1.6.0。先使用一般模式，仅追加这个服务，保留其他连接器。联网做一次真实查询；需要机构网络或个人API时再按需配置，我可以随时暂停，下次继续。不要打印账号密钥或把我的配置放回发行文件夹。

## 接入条件和选择

| 选择 | 可尝试范围 | 实际条件 |
|---|---|---|
| 一般 general | 全部无需个人凭据、无需机构网络的命令 | Python、curl、依赖与网络；公开文件类仍需相应文件 |
| 浙大内网 zju | 再开放机构网络入口 | MCP运行机器的真实校园网络与订阅，不由文件夹携带 |
| 登录 login | 再按需配置个人账号/API | 接收者自己的凭据与审批；可跳过、暂停、恢复 |

客户端须支持启动本地stdio MCP；只上传文件到普通聊天网页或只支持远程HTTP地址的平台，不能直接接通。AI使用哪个运行环境，就使用那个环境的网络；云端容器不会继承另一台电脑的校园IP。

新安装默认一般模式；同一安装目录升级时省略 `--mode` 会保留原模式和进度。安装器只生成配置时不代表已连接。重连后应能看到七个工具，再执行status、discover、help及一次真实查询。参数错误、网络失败、权限、缺文件、零命中分别处理，不能把失败算作数据不存在。

## 能力如何理解

这是可重复查询的工具，不是预先搜集好的资料包。目录里有3,753条命令入口，但其中许多尚未验证；部分只返回目录、题录、摘要或说明。`coverage`区分索引数和样例证据数；`verified_only`可筛有历史非空样例的命令，仍不保证本次可用。

正文、数值、图片和原始文件分别核验。单篇/单页成功不代表整库全文；`ok:true`不代表非空，未知内容为null也不代表没有内容。接口状态和已有登录可能变化，华案等间歇性机构识别仍以每次真实响应为准。详见[实测能力](CAPABILITIES.md)及[版本验证记录](VALIDATION.md)。

来源的用途、额度、引用、订阅和全文条件仍分别适用。公开包不携带维护者的账号、授权、个人研究材料或对厂商数据的再分发权。
